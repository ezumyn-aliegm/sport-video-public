# Public development history

This public repository preserves main's original development sequence,
commit dates, authors' names and merge relationships. Personal infrastructure
addresses, usernames, local paths, device identifiers and private author
email addresses were sanitized throughout the reachable history before
publication. Commit IDs therefore differ from the private originals.
The original private repository has not been rewritten. Unmerged side branches
remain private; the complete ancestry and merges of main are retained.

Historical commits show work in progress. They can contain obsolete setup
instructions and unresolved limitations; use the current README for setup.
Old PR numbers refer to the private development process, not public reviews.
The dated publication-preparation commit adds generic configuration and
MIT licensing. Third-party dependencies and any separately licensed vendor
assets retain their own licenses; the root MIT license covers project work.

No real client documents, family database, uploaded videos or recorded ride
logs are distributed. Credentials belong in local environment/configuration,
never in commits. A scanner finding no secrets is not proof of complete safety.
